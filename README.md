# Skeuo-Silver-Round

A custom skeuomorphic icon theme for Linux desktop environments featuring a beautiful vintage silver aesthetic with perfectly shaped round icons.

## Features
- **Round Design:** Clean, elegant circular shapes combined with detailed silver metallic borders.
- **Rich Icon Set:** Includes over 500 hand-tailored system, app, and device icons.
- **High Compatibility:** Perfectly optimized for **KDE Plasma** (supports both Plasma 5 and Plasma 6).
- **Papirus Base:** Built upon the solid foundation of the Papirus icon theme for excellent fallback coverage.

## Installation

You can easily clone this repository directly into your local icons directory. Open your terminal and run:

```bash
mkdir -p ~/.local/share/icons
git clone https://github.com ~/.local/share/icons/Skeuo-Silver-Round
```

After running the commands, open your **System Settings** -> **Appearance** -> **Icons** and select **Skeuo-Silver-Round**.
